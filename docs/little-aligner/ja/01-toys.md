# 1. Toys

> 🌐 [English](../01-toys.md) · **日本語**

**Q1.** `42` は値ですか？

**A1.** はい。`i64` です — 文脈によって他のビット幅が要求されない限りは。

---

**Q2.** `42.0` は同じ値ですか？

**A2.** いいえ。そちらは `f64` です。Align が勝手に両者を混ぜることはありません。

---

**Q3.** `x := 42` は何をしますか？

**A3.** `x` を導入し、`42` に束縛します。`:=` は新しい変数を宣言するという意味です。

---

**Q4.** では、その直後の `x = 43` は何をしますか？

**A4.** コンパイルエラーになります。`x` が `mut` として宣言されていないからです。

---

**Q5.** `x` を変更可能にするにはどうしますか？

**A5.** `mut x := 42` とします。こうすれば `x = 43` が許可されます。可変性は宣言時に決定するものであり、後から付与するものではありません。

---

**Q6.** なぜ、あとから変更できるかどうかを宣言の時点で決めるのですか？

**A6.** その変数が変わりうることを、読む人にも伝えるためです。`mut` がなければ、読み進める途中で値が変わる心配はありません。

---

**Q7.** このブロックの値は何ですか？

```align
{
    a := 3
    a * 2
}
```

**A7.** `6`。ブロックの値は、その最後の式の値になります。ブロックの中に `return` はいりません — 最後の式がそのまま答えになります。

---

**Q8.** `if 2 > 1 { "yes" } else { "no" }` の値は何ですか？

**A8.** `"yes"`。`if` は式です。それ自体が値を持つので、変数に束縛することもできます: `ans := if 2 > 1 { "yes" } else { "no" }`。

---

**Q9.** 3を渡されたとき、この関数は何を返しますか？

```align
fn square(x: i64) -> i64 = x * x
```

**A9.** `9`。`= expr` の形は、式一つだけで関数全体を書き表す構文です。

---

**Q10.** では、こちらは3を渡されたら何を返しますか？

```align
fn cube(x: i64) -> i64 {
    return x * x * x
}
```

**A10.** `27`。ブロックの本体では `return` と書きます。本体の書き方はこの2つだけで、3つ目はありません。

---

**Q11.** `square(square(2))` は何ですか？

**A11.** `16`。内側の `square(2)` が `4`、外側の `square(4)` が `16` です。

---

**Q12.** `print(7 / 2)` は何を表示しますか？

**A12.** `3`。整数の割り算はゼロに向かって切り捨てられます。

---

**Q13.** `print(7 / 0)` は何をしますか？

**A13.** ゼロ除算のエラーでプログラムが停止します。

---

**Q14.** `x: i8 := 127`。では `x + 1` は何ですか？

**A14.** `-128`。整数のオーバーフローは、2の補数表現で折り返します。仕様で決まった動作ですが、計算の目的に合っているかは別に確認する必要があります。

---

**Q15.** `[1, 2, 3]` は値ですか？

**A15.** はい。3つの `i64` がメモリ上に連続して並んだ配列です。この並び方が、次の4章のパイプライン処理で重要になります。

---

**Q16.** `[1, 2, 3][0]` は何ですか？

**A16.** `1`。インデックスはゼロから始まり、境界チェックが行われます。

---

**Q17.** `[1, 2, 3][3]` は何ですか？

**A17.** 範囲外アクセスのエラーで、プログラムが停止します。

---

**Q18.** 最後のおもちゃです。このプログラム全体は何を表示し、どの終了コードを返しますか？

```align
fn main() -> i32 {
    print("ready")
    return 0
}
```

**A18.** `ready` と表示し、終了コード `0` を返します。C と同様、戻り値の型が `i32` の `main` は、その戻り値をプログラムの終了コードにします。

---

**Q19.** すでに `x` があるとき、小さなブロックの中で2つ目の `x` を作れますか？

```align
x := 1
{
    x := 2
    print(x)
}
```

**A19.** いいえ。Align にはシャドーイングがありません。2つ目のものが何なのか — `double`、`next`、`inner` — を名前にしてください。見えているすべての `x` は、同じ `x` を意味します。

---

**Q20.** 多くの言語にある便利さを、なぜ禁じるのですか？

**A20.** 同じ名前の宣言を探し直さずに読めるようにするためです。新しい変数には別の名前をつけ、値を変更する変数には `mut` をつけます。

---

**Q21.** 実行せずに答えてください。

```align
x := 4
y := if x % 2 == 0 { x / 2 } else { x * 3 + 1 }
print(y)
```

**A21.** `2`。条件が一つの式を選び、選ばれた式の値が `y` になります。

---

**Q22.** `x := 4` だけを `x := 5` に変えると？

**A22.** `16`。今度は `else` 側の式が選ばれます。

---

**Q23.** この選択に、2度使える名前をつけてください。

**A23.**

```align
fn step(x: i64) -> i64 =
    if x % 2 == 0 { x / 2 } else { x * 3 + 1 }
```

`step(4)` は `2`、`step(5)` は `16`。同じ変換を、名前をつけて再利用できます。

---

**Q24.** `step(step(5))` は？

**A24.** `8`。まず `16`、それから `16` の半分です。呼び出しが入れ子なら、内側から外側へ読みます。

---

**Q25.** 最初にエラーになる行は？

```align
x := 3
x = 4
y := [10, 20][2]
```

**A25.** `x = 4`。`mut` のない変数への再代入はコンパイル時に拒否されるため、範囲外アクセスの行は実行されません。

---

**Q26.** 最小限の変更で、コンパイルできて `20` を表示するよう直してください。

**A26.**

```align
mut x := 3
x = 4
y := [10, 20][1]
print(y)
```

変更する変数には `mut` をつけ、配列の範囲内の添字を指定します。

---

> **第一の戒律**
>
> *`:=` で束縛せよ。`=` による再代入は、`mut` と宣言したものだけにせよ。*
