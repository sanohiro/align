# Borrowed string array roots in typed JSON decode

A top-level JSON array of strings can use the same clean/escaped text rules as an
`array<str>` record field. The existing owned `array<string>` root supplies a
separate payload-owning target. Expected-type selection determines the route.

| Contract | Implementation and acceptance |
|---|---|
| Source | With `import core.json`, `values:array<str> := json.decode(input)?` selects `json.decode(input:str) -> Result<array<str>,Error>`. One required operand, no defaults, existing string auto-borrow, evaluate once. Same purity, whole-input grammar, error and lexical arena selection as typed record decode. No ambient configuration. |
| Input and errors | Validate the complete UTF-8 JSON text using the existing typed JSON parser, including whitespace, escapes, surrogates, embedded NUL in a decoded value, empty array and trailing bytes. Require one array containing only strings. No arena: an escaped selected string yields the existing parse error (code 1). With an active arena, unescape exactly into that arena. Failure on any element or trailing input publishes nothing. A field header is 16 bytes. If the element count or count × 16 exceeds the addressable signed byte extent, return Error.Code(1) without publishing. Actual allocator exhaustion remains terminal. Check capacity arithmetic before growing staging or publishing. |
| Storage | Empty array owns null/0. Nonempty success owns one separately allocated contiguous array of str headers, including inside arenas. Unescaped fields alias input, escaped fields alias the active arena. A result's element lifetime is bounded by both possible sources; use after input mutation or arena exit is rejected, including authors returning a selected field. Outside arenas, safe function results may retain caller input. Independently obtained owned strings and numeric roots keep their existing semantics. Header replacement/Drop frees the headers exactly once; failed native calls release any staged headers. Bytes allocated in the caller's arena remain arena-owned until teardown. |
| Native | Dedicated `i32 align_rt_json_decode_str_array(ptr input, i64 len, ptr out, ptr nullable_arena)`. Input is borrowed for the call and may escape in elements; a nonnull arena is live, exclusive native state and may supply returned bytes. Output is a valid exclusive aligned AlignStr slot disjoint from input and arena. Null+zero is empty input and fails grammar, null+positive, negative or unrepresentable lengths, invalid UTF-8 all fail before allocation; errors leave output untouched. Emit status 0/1, never a partial published array. Shape A17. Key JsonDecodeStrArray, IndirectStorage/Unstated; pointer ordinals 0 and 3 may escape, ordinal 2 is semantically written and gets captures(none) without an LLVM writeonly annotation; input ordinal 0 read, arena ordinal 3 left unannotated. No release, fresh scalar pointer return or divergence attribute. |
| Parsing | Reuse the existing array-field parser and JsonParser::string_value. Keep payload staging in the existing transient vector (or a typed equivalent); delay ownership transfer until trailing validation, or guard an owned header buffer with flat cleanup on trailing failure. Test escaped/unescaped in one array, invalid UTF-8 and grammar, selected escapes without arena, failure before/after one successful element, trailing junk after a good close, empty input, exact payload aliases, sentinel out on failure. |
| Sema and MIR | Distinguish borrowing decode from independent JsonDecodeArray producers wherever source/arena/cleanup facts diverge. Track source validation generation, actual lexical arena and individual header provenance; the Result Ok carrier retains both. User input and hidden temporary sources stay live through consumption of every field, independently from header consumption. MIR validates source and active innermost arena, including the active-scope verifier prefilter and unreachable operations. Outside an arena require absence; inside require the actual innermost handle. Both whole and partition validators reject stale, substituted outer and missing-in-scope handles. At the result Ok path certify the header Owned and every selected text element Shared, exact typed output slot and status, selected element grounding, output initialization and ownership, whole and per-unit as for typed record decode. Malformed checked HIR and MIR must reject even on discarded values. |
| Control and artifacts | Bind, discard, replace, return, move into/out of Result, `?`, `map_err`, `else`, if/match/loop joins, indexed field, named arena and early exits; generic forwarding/imported functions in whole and per-unit compilation and cache replay. Test an external helper returning clean views into caller str, reject returned views into local/temporary owned or arena input, check caller UTF-8 alias writes invalidate even an extracted result after that helper, test the actual nested innermost arena for escaped elements, and exact header release with allocation probes. No new persisted file or user-facing build option. Reuse ordinary type/interface/program identity; MIR operation and input identities participate in ordinary unit hashing. Existing numeric and owned roots, and borrowed record fields, are regression controls. |
| Sources | draft §14, language-spec, design-notes, open-questions, English/Japanese core-design/json, checked-HIR ledger19 and runtime ABI ledger20. Prerequisites are scalar-array fields, owned roots and existing typed JSON arena support. No new benchmarked timing or working-set promise. |
