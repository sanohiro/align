# Preset dictionaries for existing std.compress codecs

This extends the completed whole-buffer contract in Plan226. The source operation selects the format. Gzip has no standard preset-dictionary field. One-shot dictionary support is independently useful and can be merged before stream I/O.

| Surface | Contract and owner |
|---|---|
| Calls | For each existing zlib, deflate_raw and zstd codec, compression admits (data:bytes,level:i64,dictionary:bytes) and decompression admits (data:bytes,max_bytes:i64,dictionary:bytes). Omission uses the existing signatures and defaults, including the one-argument decoder. The second argument remains the cap even with a dictionary. Empty dictionary selects the existing no-dictionary semantics. Gzip rejects the extra argument at check time. All forms return Result<buffer, Error> and are Impure. |
| Inputs and output | Evaluate data, level or limit, then dictionary once from left to right. Retain both borrowed binary views through the synchronous native call, allowing overlap with one another. Preserve the existing bytes input types, source/type diagnostics, success publication, independent owned Move output and deterministic argument cleanup. On failure no owned buffer escapes; a writable out slot is set to null. Return, Drop, reassignment, generics, modules, branch joins and early ? reuse existing buffer ownership. |
| Validation | The accepted levels are 0..=9 for zlib/raw and 0..=22 for zstd (0 selects zstd's default). The existing level and inclusive 0..=1073741824 output cap keep their current hard-error behavior. A non-fallthrough operand exits before any runtime validation. Once all operands return, validate the numeric parameter before dictionary width and contents. Configure the dictionary before examining any frame; on each decoding step an engine error takes precedence over same-step cap exhaustion. Release each initialized native state exactly once on all returns. Existing byte pointer/length ABI preconditions apply to both views. At the libz boundary an unrepresentable dictionary length (greater than uInt::MAX) returns Error.Invalid before native initialization; zstd requires a representable size_t. Preserve existing provider allocation/setup/internal error mapping, and reject corrupt/truncated input with Error.Invalid. Errors are independent of caller locale. |
| libz frames | Compression calls deflateSetDictionary once, before deflating input, for nonempty dictionaries and zlib/raw only. zlib stores the provider's 32-bit Adler identifier over the full supplied dictionary. Decoding supplies the dictionary upon Z_NEED_DICT; a missing dictionary or an Adler mismatch (Z_DATA_ERROR) yields Invalid. Provider state and allocation errors yield Error.Code. An ordinary zlib stream which does not request a dictionary still decodes. Raw RFC1951 has no dictionary ID or checksum: configure inflateSetDictionary before reading raw bits. An incorrect raw dictionary can decode different bytes without an error, exactly as allowed by the format. Preserve strict one-stream/trailing-byte and inclusive cap rules. |
| zstd frames | Use the upstream contexts with ZSTD_CCtx_loadDictionary / ZSTD_DCtx_loadDictionary. Normalize lengths below 8 to an empty dictionary for both directions. For every length >=8 beginning with the four-byte trained dictionary magic, validate entropy tables with the public ZDICT_getDictHeaderSize before creating a context. A malformed trained header returns Invalid, including on skippable-only input; provider allocation failure during validation returns Code. Other bytes are raw dictionary contents. Set the compression level before loading the dictionary; initialize the decompressor before loading its sticky dictionary. Supply the same dictionary for all frames of a concatenated input; retain skippable-frame, truncation and cap behavior. Mismatched recorded dictionary IDs are Invalid. Raw-content frames may lack an identifier or payload checksum; do not promise detection of all wrong dictionaries. Same output capacity guarantee; provider's dictionary workspace is outside the payload grant. |
| Native and cache | Extend the same compress/decompress MIR and checked HIR records with an optional dictionary operand; validate shape and permitted format even for an unused expression and before publishing per-unit summaries. Emit one selected native operation after evaluation of all arguments. New public compiler-to-runtime keys use align_rt_compress_{zlib,deflate_raw,zstd}_{compress,decompress}_dict, each i32(ptr data,i64 data_len,i64 level_or_limit,ptr dict,i64 dict_len,ptr out). At success the last argument receives one independently owned Buffer handle; ordinary failure clears a writable slot to null, as in Plan226. Foreign/Unstated, no readonly or nocapture promise, conservatively mark [0,3,5] as escaping. The six no-dictionary symbols keep their existing ordinary dispatch and produce no new hidden data dependency. No new dependency or change to archive capability closure. Stable structural hash and MIR reveal presence, order, and exact operands. Sync the ABI signature/effects golden and English/Japanese library contracts. |
| Acceptance | Independently created zlib/raw/zstd dictionary frames, alternating distinct dictionaries, wrong/missing/empty dictionary, newline and zero bytes, empty payload, max=0/exact/short, concatenated zstd/skippable, trailing zlib/raw data, legacy no-dictionary/gzip controls. Whole and warm per-unit real programs, invalid argument order/shape, dropped owned results and allocation parity. Inspect independent upstream decoder interoperability as well as roundtrips, including a trained zstd dictionary with explicit id. Seed every out slot with a non-null sentinel in the failure owner. Cover 7/8-byte dictionaries, truncated trained entropy tables on both operations, malformed dict + skippable-only input, non-fallthrough argument ahead of numeric validation and wrong-ID later frames after an exact-cap valid prefix. No speed or ratio promise. Existing provider scratch is allowed. |

## Implementation closure

| Boundary | Implementation and verification |
|---|---|
| Source, generic replay and argument lifetimes | Add the optional view to existing checked HIR. Extend `hir_depth`, replay cloning, effect/capture inspection, escape and move traversal and source-order protection. Existing source `compression_framing` tests cover input invalidation from the cap expression. Extend to a third dictionary expression that rebinds, mutates via an alias or moves the original input; include a legal shared-overlap case, a retained independent owned result and a non-fallthrough later argument. No new owner types. Existing buffer return, move, cleanup, branch/join and `?` fixtures remain controls. |
| Checked HIR and MIR | Extend `validate_hir` and `producer` admission for the optional byte view and disallow dictionaries for gzip in every direction, including discarded ops. Ensure `producer` operand visitors validate every operand and `print` preserves the previous no-dictionary representation. Regress wrong-typed optional operand, unavailable SSA value, forbidden kind and wrong native output slot before whole/unit publication. |
| Native result and cleanup | The existing source ABI keeps four-argument functions intact; the six new wrappers use the same parameterized format-specific code and result-slot publication. Before forming slices validate length conversion and the libz width bound. Preserve public numeric hard errors and the existing strict framing splitter. Every successfully initialized context reaches end/free on success, wrong data or dictionary, cap, short/trailing frame, and allocation failure. No provider state escapes. Add independent golden dictionary frames, trained header and native failure-with-seeded-out-slot controls alongside the existing codec frame tests. |
| ABI, caches and interoperability | Update the native inventory (six keys, signature and conservative escape operands), codegen owner, stable printer, and runtime export-count owner. Whole and cold/warm separate-unit source programs use only z/zstd. Python's zlib and a separate C API Zstandard consumer generate reference frames; native reference decoders consume the Align compressor outputs. The same selection closes zlib/RFC1950 and raw RFC1951 even though their dictionary handoff occurs at different steps. |
| Change size | Each selected public call needs source admission, provenance/ordered evaluation, native publication and independent frame decoding to exercise it. The four-layer path and its denials ship together; separating a dormant ABI or frontend-only path would repeat the same proofs. Zlib and Zstandard are independently testable engines behind the same new source arity. No timing or compression ratio is a release criterion. |

Provider definitions: https://www.zlib.net/manual.html and https://facebook.github.io/zstd/zstd_manual.html .
