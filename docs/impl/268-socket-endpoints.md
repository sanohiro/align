# Source and local socket endpoints

The UDP echo needs the sender of each datagram and a discoverable local port. The socket supplies both. The ordinary Move record machinery used by `fs.dir_entry` can return the numeric address in an owned string.

| Surface | Public, compiler and native contract |
|---|---|
| Types | Under import std.net, net.endpoint { host: string, port: i64 } and net.datagram { n: i64, peer: net.endpoint } are ordinary Move records with the documented field order. Host is numeric, owned UTF-8 text, contains no brackets or port, is never reverse-resolved, and survives either handle and buffer Drop/reuse. IPv4 is dotted-decimal; IPv6 uses the standard Rust IPv6 textual form, with a nonzero interface scope ID appended as % followed by unsigned decimal when present. Preserve mapped IPv6 as IPv6; port is the host-order numeric u16 widened to i64. No public allocator/credential or process ambient state. Construct, move, clone where the ordinary owned-string graph allows it, project a borrowed str, return, match, ? or discard by the normal record and Drop rules. Resolve reserved qualified builtin identities and authenticate exact field graphs in checked HIR, source and MIR producer; reject a lookalike. A module referencing one of the two qualified records only in a type position counts as using std.net; qualified identity and Move cleanup survive interface roundtrips, including the nested peer record. |
| Binding | tcp.listen(host: str, port: i64) -> Result<tcp_listener,Error> and udp.bind(host: str, port: i64) -> Result<udp_socket,Error> now include 0 as a request for a kernel-assigned port. Encode service zero as NUL-terminated ASCII 0, keeping the existing positive-destination policy for http.serve and http.serve_shared even though they share the listener helper. All other inputs, resolver ordering, wildcard and host behavior follow existing bind semantics. tcp.connect and udp_socket.send_to keep requiring a destination port in 1..65535. Explicit shared receiver listener.local_addr() or socket.local_addr() -> Result<net.endpoint,Error> inspects the actual socket via getsockname; use the same operation on tcp_conn for consistency with connected socket queries. An unspecified bound address stays 0.0.0.0 or ::, not a guessed reachable address. Source/HIR reject use after move. Each native non-null handle must be live and have the promised type, and out must be fresh writable, appropriately aligned and nonoverlapping with the input objects. Reject null handles and return the mapped fd error on a locally owned invalid fd; reject malformed/truncated address metadata before publication. No per-process port cache or reserved-port workaround. |
| Receiving | u.recv_from(buf) -> Result<net.datagram,Error> replaces the count-only return. Receives one datagram in caller storage by the existing exclusive buffer argument/owner-liveness rule. No implicit DNS lookup. n is the initialized prefix that fit, up to capacity; a truncated remainder is discarded by the socket. Empty wire payload is success with n=0 and actual peer. Zero capacity yields Error.Invalid immediately, before any receive: it cannot produce an honest peer without consuming a message. Positive capacity receives on the bound fd, retrying EINTR, and maps syscall failure by the existing errno table. Null handle/invalid output evaluation precedes any buffer mutation, zero capacity precedes consuming a packet. A datagram received from a source with port zero may report zero even though send_to rejects zero as a destination. |
| Native layout and publication | Replace the old native align_rt_udp_recv_from export with the distinct align_rt_udp_recv_datagram symbol for UdpRecvFrom to fail closed against old archives. The signature is i32(ptr sock,ptr buf,ptr out), returning status and writing one flat repr(C) initialized observation matching n:i64, host_ptr:ptr, host_len:i64, port:i64, size 32 align 8 on all supported targets. For socket local address use typed runtime keys TcpConnLocalAddr/TcpListenerLocalAddr/UdpLocalAddr i32(ptr handle,ptr out) and repr(C) host_ptr,host_len,port (24/8). On all entries require a writable out pointer then initialize it to all-zero; null handles and zero capacity return Invalid without allocation. Storage preparation failure sets logical buf.len=0 and returns Invalid with out zero, before receiving or allocating host bytes. A bad out or null handle leaves an otherwise valid buffer unchanged. For either syscall use zero-initialized sockaddr_storage, initialize returned socklen_t to actual capacity on every retry and retry EINTR, including getsockname. Check at least the family bytes and at most physical capacity before reading the family, then require the exact platform sizeof(sockaddr_in) or sizeof(sockaddr_in6) for its family. Darwin additionally requires sa_len equal to returned socklen_t, reads family at byte 1, and Linux reads its native sa_family_t at offset 0. No typed address reads before complete shape validation. Before publication validate address family and length, convert scope number and port using platform sockaddr rules, construct exactly one owned host payload compatible with the normal Align string destructor, transfer into the return record once. No additional heap shell retained. On an unsuccessful syscall or unsupported source metadata after receive, return mapped errno or Invalid with out zero; logically clear buf.len on receive/metadata failure and expose no partially filled bytes. On success publish the caller buffer length and the complete record atomically from the single caller's point of view. Never publish a Rust CString or Vec allocation with incompatible destruction. User-visible allocation is for one owned host string per successful call, including a zero-length datagram. Existing heap allocation failure policy applies. |
| Implementation | Evaluate bound named receiver then optional buffer once; ensure write authority and retain each handle while evaluating later operands. All native calls Impure. Use the existing checked native HTTP/fs/OS record producer and imported builtin record infrastructure for ordinary nominal types, region/root summaries, native output cleanup, drop/replacement, partial move and early control-flow. Whole/per-unit compilation and generic functions refer to the same qualified record shape, no synthetic user-visible typedefs or duplicate runtime paths. Artifact runtime link and ABI signature fingerprint must change for changed arity; old bitcode/object caches rebuild prior to linking. Use separate repr(C) native scratch plus fieldwise transfer into the actual ordinary Align record indices; Align may physically reorder fields. Keep both record graphs and fields authenticated at emission. Include a stale-link-symbol negative, exact native struct offsets on each platform, type-only import usage, a wrong nominal peer and forged interface Move cleanup. |
| Acceptance | Direct Align echo binds UDP on port 0, reports its actual port, receives packets from two independent senders and replies to each record's host and port, without side channels or races. HTTP serve/shared zero and destination-zero negative controls exercised through the shared bind builder. TCP bind(0)/local_addr on listener and connected/accepted sockets, nonzero ports and destination 0 rejection. IPv4, IPv6 loopback when available and offline IPv6 scope vectors using native layouts on both supported OS families. Empty datagram with positive capacity, oversized packet/truncation, prefilled/zero-cap buffer, closed/invalid descriptor errors, malformed native address metadata, injected EINTR resetting addrlen, truncated/oversized sockaddr and Darwin sa_len mismatch, pre-receive storage failure and null output controls. Reuse or drop the buffer/socket while consuming the peer host; Move out, branch join, early return, map_err and ignored result release exactly one payload; heap-allocation identity and ELF wrapper where applicable. Reject insufficient authority and overlapping buffer view. Check whole/imported generic/cold/warm result, field layouts and status mapping, forged checked HIR and MIR including dead result, native declaration and export audit. Change English/Japanese std-design/net, language specification/digest, design notes, settled register, roadmap and runtime ABI as needed. Bundling getsockname with recvfrom shares the exact portability, ownership, native publication and echo acceptance proof; the integration can exceed 1,000 hand-written lines. No rate or latency guarantee. |

## Implementation closure

| Boundary | Implementation and owner |
|---|---|
| Source and interface | `net::definitions` provides both nominal records. Qualified-name resolution, type-only import discovery and interface return cleanup use the same field graph. `datagram_records_across_cached_module_boundaries` runs a generic producer and a type-only consumer in whole, cold and warm unit builds. The interface mutation owner checks the Move cleanup bit for both records. |
| Handles, control flow and storage | Both operations read a bound handle. Receive requires an exclusive local buffer. Their native output is a fresh ordinary record slot, then the standard status-to-Result branch constructs its active arm. `recv_from_requires_exclusive_buffer_and_local_handle` covers temporary, immutable and live-view rejection. `exactly_once_endpoint_cleanup` tracks all eight host allocations through early failure, propagation, field move-out, branch join, buffer reuse and discard. |
| MIR and native publication | `socket_observation_schemas_and_output_producers` mutates the nominal and nested graphs, status, buffer, raw argument and output slot for whole and emitted partition validation. `net_endpoint::tests` covers platform address layout, EINTR retry, buffer capacity and errors. The runtime export audit requires the new signatures and rejects a legacy exported receive symbol. |
| End to end | `udp_bind_send_to_recv_from_roundtrip` receives from two independent senders, including truncation and an empty packet. `tcp_listen_accept_serves_two_clients`, `tcp_connected_local_addr` and `udp_local_address_survives_handle` cover the remaining entry points. Native tests exercise IPv6 and the HTTP bind policy. |
