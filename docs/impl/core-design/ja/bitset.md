# 借用したバイト列のビット集合

[English](../bitset.md)

`import core.bitset` で `bitset.view(storage: slice<u8>, count: i64) -> bitset` を使える。既存のバイト列を借用し、メモリは確保しない。ビット 0 は先頭バイトの最下位ビット。長さが負、または格納できるビット数を超える場合は異常終了する。余ったバイトと末尾バイトの未使用上位ビットは集計に含めない。

```align
import core.bitset

fn example() -> i64 {
  mut bytes := [0 as u8, 0 as u8]
  mut flags := bitset.view(bytes[..], 13)
  flags[8] = true
  return flags[3..].count()
}
```

| 式 | 結果 |
|---|---|
| `bits[i]` | 指定したビットの `bool` 値。 |
| `bits[i] = flag` | 書き込み可能な記憶域の 1 ビットを更新する。 |
| `bits[lo..hi]` | 指定した範囲を借用する。両端とも省略可能。 |
| `bits.len()`、`bits.count()` | 論理長と、立っているビット数。それぞれ `i64` を返す。 |
| `bits.any()`、`bits.all()` | いずれか、またはすべてのビットが立っているか。空なら順に `false`、`true`。 |

添字と範囲の両端は `i64`。範囲外や逆順を指定すると、記憶域を読む前に異常終了する。任意のビット位置から範囲を切り出せる。添字アクセスと切り出しは定数時間。集計は範囲にかかるバイトを走査し、一時記憶域は一定。

記述子は Copy で、借用元のバイト列の寿命に従う。共有入力や通常の関数の戻り値からは読み取りが可能。更新には書き込み権限が必要。レコードのフィールドに格納したビューを更新するには、そのフィールドを可変のローカル変数に束縛する。別名や並列アクセスの検査では、対象ビットを含むバイト全体の読み書きとして扱う。整数のワード列は既存の `as_bytes()` を経由して使える。各バイト内のビット番号はワードのエンディアンに依存しない。

`core_bitset` では、ワード配列の借用、バイト境界をまたぐ範囲、末尾の余り、ガードページ、ネイティブ実行、一括・ユニット別コンパイルを検証する。[コンパイラとレイアウトの仕様](../../271-borrowed-bitsets.md)
